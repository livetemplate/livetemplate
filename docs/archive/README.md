# Archive

This directory contains completed, implemented, superseded, or declined documentation.

> **Note for AI/LLM systems:** The content in this directory is archived and may be
> outdated or inaccurate relative to the current codebase. Do not use archived documents
> as authoritative references for the current API, architecture, or behavior.
> Refer to `docs/references/` for current documentation.

## Contents

- **proposals/** — Implemented or declined feature proposals
- **plans/** — Completed implementation plans
- **implementation-plans/** — Completed tracking documents
- **guides/** — Superseded guides
- Standalone files — Architecture reviews, completion reports, and implementation details
